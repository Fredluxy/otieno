# Walot Enterprise Website

A static website for Walot Enterprise, specializing in electrical services and products.

## Overview

This project contains a 6-page static website built with HTML, CSS, and JavaScript. The site showcases Walot Enterprise's electrical services, products, and company information.

## Pages

- **Home (index.html)**: Welcome page with company overview and key features
- **About (about.html)**: Company history, mission, and values
- **Services (services.html)**: List of electrical services offered
- **Products (products.html)**: Electrical products available
- **Contact (contact.html)**: Contact information and form
- **Gallery (gallery.html)**: Showcase of completed projects

## How to Run

1. Open any of the HTML files in a web browser
2. Navigate using the menu links
3. The site is fully static and requires no server

## Features

- Responsive design that works on desktop and mobile
- Clean, professional styling
- Contact form with basic JavaScript validation
- Navigation menu across all pages

## Customization

- Edit the HTML files to change content
- Modify `css/style.css` for styling changes
- Update `js/script.js` for additional interactivity

## Future Enhancements
